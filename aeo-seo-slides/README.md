## Using them

- **On screen** — open any file in a browser. Full-screen the tab and it presents as-is.
- **As PPT / PDF** — print to PDF (Cmd/Ctrl-P). The print stylesheet sets the page to
  13.333in × 7.5in, i.e. standard 16:9 PowerPoint, and drops the screen shadow and
  rounded corners. Drop the resulting PDF pages into a deck, or use each PDF page as a
  full-bleed slide background.
